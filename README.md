# Strong Waters Bartending LLC

A static website for Strong Waters Bartending LLC showcasing mobile bartending services, pricing, sponsor submissions, and booking details.

## Pages
- `index.html` — home page with service details, pricing, and booking form
- `about.html` — owner story and business details
- `sponsors.html` — sponsor request form and partnership information
- `contact.html` — contact page
- `careers.html` — career opportunities

## Tech
- HTML
- CSS
- JavaScript

## Preview
Open `index.html` in your browser to preview the site locally.

## Deployment
This site can be published using GitHub Pages from the `main` branch.

## Notes
- All assets are stored in the `assets/` folder
- The site is currently a static, client-side website
